Forgeon Clinic — referências visuais

HTMLs originais do export do Claude Design, preservados como referência. Rodam direto do disco (precisam de internet para React/Babel do unpkg). A biblioteca viva está em design-system/components e na rota /design-system do app. E-mails: confirmação pt-BR · recordatorio es-ES.

Fundações — cores, tipo, espaçamento

  • Forgeon brand accentIndigo → violet. Logo, AI/agent moments, badges only
  • Chat & WhatsAppBubble surfaces; WhatsApp green only on WhatsApp elements
  • Dark mode (painel)data-theme="dark" — semantic aliases remap
  • Ink (text)Cool navy text scale on warm grounds
  • Warm neutralsSand grounds, surfaces and borders
  • SemanticBase / text / surface triplets
  • Appointment statusConfirmada · pendente · cancelada · faltou · remarcada
  • Clinic TealPrimary — actions, links, active states
  • Focus & touch targetsAlways-visible focus ring; 44px minimum, 48px for patient UI
  • MotionShort, quiet fades and slides; zero under prefers-reduced-motion
  • Corner radii12–16px for cards and controls; pill for badges
  • Spacing scale4px base; generous breathing room
  • ElevationSoft, low-contrast, navy-tinted shadows
  • Text — InterUI and reading text; 16px minimum for patient-facing copy
  • Display — ManropeHeadings, KPIs, marketing
  • Mono — template variablesJetBrains Mono, only for {{variáveis}} in message templates
  • Type scaleDisplay → overline
  • Tabular numeralsfont-variant-numeric: tabular-nums for times, dates, KPIs
