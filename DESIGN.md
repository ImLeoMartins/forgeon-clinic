# Forgeon Clinic — Design System

This file is the visual contract and the **source of truth for every design token** in this repository. The YAML front matter above is normative; `design-system/tokens/*.css` mirrors it one-to-one (same names, `--` prefixed), and `npm run lint:design` fails when the two drift. Change a value here first, then in the CSS.

Token naming: color tokens use the CSS custom property name without `--` (`teal-600` → `var(--teal-600)`). Semantic aliases reference base tokens (`{colors.teal-600}`). Dark-theme values are the same semantic names prefixed with `dark-` and live in `design-system/tokens/theme-dark.css` under `[data-theme="dark"]`. `primary`, `secondary`, `tertiary` and `neutral` are role aliases required by the DESIGN.md format.

## Overview

Forgeon Clinic is a SaaS by **Forgeon** (forgeon.dev — "Digital Products & Technology"). It puts an **AI agent on the clinic's WhatsApp** for **dental** and **psychology/therapy** clinics in **Brazil and Spain**. The agent books, reschedules and cancels appointments, sends reminders and confirmations, answers common questions, and **hands the conversation to the reception team** when a person is needed.

Surfaces:
1. **Painel (clinic web panel)** — agenda per professional, WhatsApp conversations with human handoff, patients, message templates, metrics. Light by default, dark mode available.
2. **Site / landing** — sales page with demo request and WhatsApp CTA. Light only.
3. **Messages & e-mails** — WhatsApp templates (with `{{variables}}`) and transactional e-mails.

All UI copy ships in **pt-BR** and **es-ES**.

**Look and feel:** calm health — warm, clear, professional; never hospital-cold, never alarmist. Warm sand grounds, white cards, cool navy ink, one teal primary. Generous breathing room and large touch targets. The Forgeon indigo→violet gradient is a brand accent, not a UI color.

**Voice (summary — full rules in `design-system/guidelines/content.md`):** short sentences, one idea per sentence. pt-BR uses **você**, es-ES uses **tú**; the clinic speaks as "nós"/"nosotros". Patient name first ("Oi, Marina!"). Sentence case everywhere. Buttons are verbs. 24h clock (`14:30`), `15/10`, decimal comma (`92,4%`), tabular numerals. No emoji from the agent or the UI. Urgency without alarm: state facts and the next step.

## Colors

- **Clinic Teal (primary, `teal-500` #0E8C80):** brand teal for icons, indicators, focus rings and brand fills. Because #0E8C80 is 4.1:1 on white, **text and filled buttons use `teal-600` #0B7A70** (5.2:1, AA) — that is `action-primary`.
- **Mint (`teal-50` #E6F5F2):** selected states and soft surfaces (`surface-selected`, `bubble-agent`).
- **Sand (neutral):** warm grounds (`sand-50` #FAF8F5 app background) and borders; cards are white (`sand-0`).
- **Ink:** cool navy text scale (`ink-900` #1C2430 strong text).
- **Forgeon indigo → violet (`brand-gradient`, #4F3BF5 → #8E3BF3):** only the logo symbol and the occasional "Novo" badge. Flat indigo (`ai-*`) marks **AI/agent** moments: the sparkles label, "Agendada pela IA", AI KPIs.
- **Semantics:** success #2F9E62, warning #D99A1E, danger #D2453D (urgent handoff), info = teal — each with a darker `-text` and a tinted `-surface`.
- **Appointment status:** confirmed (green), pending (amber), cancelled (ink/sand), noshow (red), rescheduled (indigo). Status is never color-only: dot + label.
- **WhatsApp green #25D366:** only on WhatsApp elements (CTA button, WhatsApp glyph). Chat bubbles are never green.
- **Dark mode** (`data-theme="dark"` on `<html>` or any container — used by the panel): deep navy grounds (#11161D / #181F28), brighter teal #1A9C8E for actions, lighter indigo for AI. Same semantic token names; components switch automatically.

## Typography

- **Manrope** (700–800, tight −1 to −2.5% tracking) for headings, KPIs and the "Clinic" wordmark.
- **Inter** (400–600) for UI and reading text. Body is 16px minimum for patient-facing text; 15/22 (`body-ui`) is allowed in dense panel UI.
- **JetBrains Mono** only for `{{template variables}}`.
- Tabular numerals (`font-variant-numeric: tabular-nums`) for times, dates, counts and KPIs.
- Uppercase only for tiny overlines and day labels (QUA, JUE) with 0.08em tracking.
- Fonts are self-hosted (woff2, latin + latin-ext) in `design-system/assets/fonts/` and declared in `design-system/tokens/fonts.css`. Never load them from a CDN.

## Layout

4px base unit with generous breathing room: 24px card padding, 20–28px page gutters, 88px (`section-y`) section rhythm on the landing.
- **Panel:** fixed 248px sidebar (`sidebar-w`) + 64px topbar (`topbar-h`); content max 1200px (`content-max`).
- **Landing:** 1200px container, two-column hero, alternating white bands.
- **Touch:** controls 44px by default (`control-h-md`, `touch-min`), 48px for time slots and patient-facing taps (`touch-comfort`), 52px for large CTAs (`control-h-lg`).

## Elevation & Depth

Hierarchy comes from warm tonal layers (sand app background → white cards → mint selection) plus soft, low-opacity, navy-tinted two-layer shadows (`rgba(28,36,48,…)`). Four steps: `xs` resting cards, `sm`, `md` popovers and feature cards, `lg` dialogs, toasts and the hero chat. Focus is always visible: `0 0 0 2px surface, 0 0 0 4px teal-500`; inputs get a teal border plus a 3px teal halo. Transparency and blur only in two places: the landing's sticky nav (88% sand + 12px blur) and the 40% navy dialog scrim. No gradients behind content, no textures; hatched pattern only for blocked calendar time.

Motion is quiet: 120ms hover/press, 200ms menus/tabs, 320ms dialogs, `cubic-bezier(.2,.7,.2,1)`. Fades and short slides only — no bounce, no spring. All durations collapse to 0 under `prefers-reduced-motion`.

## Shapes

12px controls (`md`), 16px cards (`lg`), 24px dialogs and pricing cards (`xl`), 28–32px hero/CTA panels, pill for badges, tags and counters. Icons are Lucide (rounded caps/joins, 24px grid) at 1.75 stroke (2 at ≤14px); feature icons sit in 40–48px rounded-square tiles (teal-50 or ai-surface).

## Components

The implemented library lives in `design-system/components` and is imported from `@ds` (`design-system/index.ts`). The `/design-system` route renders every component in every state, in both themes. Component tokens below are the canonical recipe; the React components implement them.

- **Button** — primary · secondary · soft · ghost · danger · whatsapp; sm 36 / md 44 / lg 52; states default, hover (one step darker), active (`scale(.98)` + one more step), focus ring, disabled (45% opacity, not-allowed), loading (spinner, aria-busy). One primary per view. Labels are verbs.
- **IconButton** — ghost · secondary · primary · soft; required `label`; optional dot/count badge.
- **Forms** — Input, Select, Textarea share `Field` (label, hint, error) and one control box: default, focus (teal border + halo), error (danger border + red halo, message explains the fix), disabled. Checkbox and Radio share `Choice`; Switch for settings that apply immediately. 44px row targets.
- **Display** — Card (outlined, elevated, flat, selected; no colored left-border accents), Badge (9 tones, sm/md, dot, icon), Tag (filter chip: selected, count, removable), Avatar (initials or photo, 6 hashed tones, presence dot).
- **Navigation** — Tabs: underline for page sections, segmented for view toggles; counts and urgent counts.
- **Overlays** — Dialog (default, danger, ai), Toast (info, success, warning, danger, ai; bottom-right, ~5s), Tooltip (4 placements).
- **Chat** — ChatBubble (patient white, agent mint with sparkles label, human slate with headset label, system pill; sent/delivered/read ticks), ConversationItem (unread, urgent "Aguarda humano", handled by agent or reception).
- **Clinic** — StatusBadge, AppointmentCard, TimeSlots (48px, unavailable struck through, AI-suggested sparkle), WeekCalendar (status tints, blocked ranges, now line), HandoffAlert (normal / urgent — calm, factual copy), PatientTable (empty state), KpiCard (delta, sparkline, AI tone).
- **Logo** — lockup = symbol + "Clinic" (Manrope 700); endorsed adds "by FORGEON"; tones color / ink / white. Clear space ≥ 0.5× symbol height; minimum symbol 16px. Never redraw the symbol.

## Do's and Don'ts

- Do use `action-primary` (teal-600) for text and filled buttons; keep teal-500 for icons, indicators and focus.
- Do keep one primary button per view; use secondary/ghost for the rest.
- Do show status with dot + label, never color alone, and keep WCAG AA contrast on all text.
- Do use tabular numerals, 24h times and decimal comma; write in sentence case.
- Do take every color, font, spacing, radius, shadow and duration from tokens (`var(--…)` or the Tailwind utilities generated from them). Raw hex, raw `px` strings and non-system fonts fail `npm run lint`.
- Do build new UI from `@ds` components; add a missing component inside `design-system/components` (see `design-system/README.md`).
- Don't use WhatsApp green outside WhatsApp elements, and never for chat bubbles.
- Don't use the brand gradient as a background or on UI controls — logo and "Novo" badge only.
- Don't use emoji in UI, headings, buttons or e-mails (patients' emoji are rendered as-is).
- Don't write alarmist copy ("EMERGÊNCIA!"); state the fact and the next step. The agent never answers clinical or urgent questions — it hands off.
- Don't add colored left-border accents, textures, stock "doctor with stethoscope" imagery or cold blue tints.
